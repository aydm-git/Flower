Чечектер — Цветочный магазин на Flask
Добро пожаловать в репозиторий нашего проекта! Это веб-приложение для цветочного магазина, написанное на Python с использованием фреймворка Flask. 

О проекте
Сайт представляет собой одностраничный лендинг с каталогом популярных букетов и формой оформления заказа. Проект создан в учебных целях для отработки навыков командной разработки, работы с Git и веб-фреймворком Flask.

Функционал:
Просмотр каталога цветов (карточки с фото, названием и ценой).
Форма заказа (имя, телефон, выбор букета).
Валидация формы (проверка, что имя и телефон заполнены).
Отображение сообщения об успешной заявке.

Технологии
Python 3 — язык программирования.
Flask — веб-фреймворк.
HTML5 / CSS3 — верстка и стилизация.
Jinja2 — шаблонизатор (встроен в Flask).
Git / GitHub — контроль версий и совместная работа.
